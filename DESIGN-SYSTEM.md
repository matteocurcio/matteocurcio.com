# Design System

This project uses the **Website** design system.

Canonical source:

`/Users/matteo/Documents/Projects/01-Design Systems/Website`

The implementation lives primarily in:

- `src/styles/global.css`
- `src/layouts/BaseLayout.astro`
- shared components under `src/components/`

This system is separate from the compact app system in `01-Design Systems/Code`.
The website is warmer and more editorial: cream backgrounds, terracotta accent,
large image-led cards, expressive headings, and a portfolio/blog rhythm rather
than a dashboard/tool interface.
